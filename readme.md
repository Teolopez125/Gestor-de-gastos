# Expense Tracker

Aplicación web para registrar y administrar gastos personales. Permite agregar, eliminar y filtrar gastos, además de calcular automáticamente el total gastado y guardar la información en el navegador.

## Tecnologías

* HTML5
* CSS3
* JavaScript
* LocalStorage

## Funcionalidades

* Agregar nuevos gastos
* Registrar descripción, monto, categoría y fecha
* Eliminar gastos
* Filtrar gastos por categoría
* Calcular el total gastado
* Mostrar la cantidad de gastos registrados
* Persistencia de datos mediante `localStorage`
* Diseño responsive para dispositivos móviles

## Conceptos aplicados

* Programación Orientada a Objetos
* Clases y objetos en JavaScript
* Arrays
* Funciones
* Manipulación del DOM
* Eventos
* `localStorage`
* Métodos de arrays como `filter()` y `forEach()`
* Validación de formularios
* Diseño responsive con CSS

## Uso

No requiere instalación de dependencias ni configuración adicional.

1. Clonar el repositorio.
2. Abrir `index.html` en el navegador.
3. Comenzar a registrar gastos.
